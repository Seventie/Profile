# Resume Website

This is a minimal Vercel-ready static website that displays `resume.pdf` and provides a download button.

## Update the Resume

Replace `resume.pdf` with the latest PDF, commit the change, and push to GitHub. Vercel will redeploy automatically if the GitHub repository is connected to Vercel.

## Deploy on Vercel

1. Push this folder to a GitHub repository.
2. In Vercel, create a new project from that repository.
3. Use the default settings. No build command is needed.

The site entry point is `index.html`.
